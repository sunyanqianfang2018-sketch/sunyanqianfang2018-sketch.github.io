# Yanqianfang (Tommy) Sun

Personal portfolio for UX research, UX design and service design.

Website: https://sunyanqianfang2018-sketch.github.io/

## Update the website

Edit the HTML, CSS or JavaScript files in this repository and commit to main. GitHub Pages publishes the root folder of the main branch. No build tools or package installation are required.

The three enterprise experience pages describe roles and scope. Internal research findings and company materials are not shared publicly.

The CV page includes a Print / save PDF control. Email links open the visitor’s email application.
